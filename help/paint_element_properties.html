To change an element's settings

  1. Select the element with the Pointer tool .
  2. On the Page menu, click Element Properties, change the settings, and then click OK.

Notes

  • To edit the element's HTML directly, on the Page menu, click Edit Element HTML. Scripts are removed, for everyone's safety, including yours.
  • To edit an element's text in place, on the Page menu, click Edit Element Text, or press ENTER.
  • Elements that show something from your site, such as a counter or a folder view, also open their settings when you double-click them.
