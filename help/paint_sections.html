To write in sections

Sections are for writing more than a few words: a blog post, an about page, your thoughts on the ending of a TV show. They stack in a column, one under another, and grow as you type.

  1. In the toolbox, click , and then click the page. The first section starts where you click.
  2. Type. While you're writing, the Font toolbar adds a Style list (Normal, Heading 1–3, Quote, Code), bulleted and numbered lists, a horizontal rule, and a link button.
  3. To add another section, click the Section tool again. New sections go under the others.

Notes

  • To change the order, select a section and press the UP ARROW or DOWN ARROW key, or drag it. Dragging the first section moves the whole column.
  • To set where the column is and how wide it is, use Page Style .
  • Pictures you add while writing a section go into its text, and are shrunk to fit the column.
  • Each section has a name, so you can link straight to it. To copy a link to the selected section, on the Page menu, click Copy Link to Section. To rename it, use Element Properties.
  • The Contents element lists the page's sections, each a link to it. The first section's heading becomes the page's title.
  • On the published page, sections flow like normal web text, so a visitor with big fonts pushes them down instead of over each other.
