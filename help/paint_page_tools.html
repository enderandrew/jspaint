The page tools

The tools below the groove in the toolbox are for building the page. The tools above it are the classic Paint tools, untouched, as is tradition.

PointerSelects, moves, resizes, and edits page elements. Double-click an element to edit it.
Select ElementsDrag a box to select several elements at once, and move or delete them together.
Text BoxPlaces text on the page. Make it big for a heading, or make it scroll.
Web TextLike the Text tool, except the words stay words: editable later, and they can be a link.
SectionA section of writing. Sections stack in a column and grow as you type.
DividerA horizontal line, like it's 1997.
LinkMakes the selected element, or the selected words, a link.
GIF PickerFinds animated GIFs from GifCities to put on the page.
PicturesYour site's pictures and photos, and Upload.
TableA table you can type in.
GuestbookA guestbook visitors can sign.
Visitor CounterCounts your visitors. Possibly both of them.
Last UpdatedShows when the page was last saved.
Folder ViewLists the pages in a folder of your site, such as your blog posts.
ContentsLists the page's sections, each a link to it.
Page StyleThe page's background color, wallpaper, and sections column.

Notes

  • To place an element, click its tool, then click the page (for the standard size) or drag a box (for your own size). Paint switches to the Pointer tool afterward, so you can move the new element right away.
  • Link, GIF Picker, Pictures, and Page Style open a window instead of placing something.
  • Every element is also on the Page menu, under Insert. So is Raw HTML, for people who know what they're doing, or think they do.
