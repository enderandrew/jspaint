To see and arrange layers

On the View menu, click Layers.

Notes

  • The Layers window lists everything on the page from top to bottom: web text, stickers, page elements, and the picture itself at the bottom.
  • Click a row to select that layer on the page. Use the row's buttons to move it up or down, flatten it into the picture, or delete it.
  • Web text is always above stickers, which are always above other elements, so layers move up and down only among their own kind. It's a strict household.
