To save as an animated GIF or a web page

  1. On the File menu, click Save as Animated GIF or Save as Web Page (HTML).
  2. Choose where to save the file.

Notes

  • Save as Animated GIF saves the picture with everything on it, and the GIF stickers keep animating. It's ready to paste into a chat, where it belongs.
  • Save as Web Page saves the page as one .html file, with everything inside it, that you can open in any browser. You can open it in Paint again later, with every element still editable.
