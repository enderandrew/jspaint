About making web pages in Paint

In this version of Paint, your picture is a web page. Paint it like any picture, then put things on it (text, GIFs, photos, a guestbook) and publish it to the web. It's how websites were made in 1999, minus the tears.

  • The picture is the page. Everything you paint with the regular tools is the page's background. The classic tools at the top of the toolbox work as they always have.
  • Page elements float on top. The page tools below the groove in the toolbox place elements on the page: text, sections of writing, GIFs, pictures, tables, a guestbook, a visitor counter, and more. They stay real web page parts, so visitors can select the text and click the links.
  • You can paint under elements. While a paint tool is selected, elements let your strokes through, so you can paint behind them. To arrange elements, use the Pointer tool .
  • Putting it on the web. Click Publish at the top right. Paint signs you in and helps you name your site if needed. After that, Ctrl+S publishes your changes.
  • Saving without the web. On the File menu, Save as Web Page saves the page as one .html file you can open in any browser. Save as Animated GIF saves it as a GIF, with the GIFs on it still animating.
